<CodeGroup>
```bash npm
npm install @yarahdev/sdk@latest
```

```bash yarn
yarn add @yarahdev/sdk@latest
```

```bash pnpm
pnpm add @yarahdev/sdk@latest
```
</CodeGroup>

```javascript
import { createClient } from '@yarahdev/sdk';

const yarah = createClient({
  baseUrl: 'https://your-app.apps.yarah.dev',
  anonKey: 'your-anon-key'  // Optional: for public/unauthenticated requests
});
```

Find the anon key with `npx @yarahdev/cli secrets get ANON_KEY`, or in the dashboard: click **Install** and open **API Keys**.
